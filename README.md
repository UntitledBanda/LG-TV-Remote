# LG TV Remote

A desktop remote control for LG webOS TVs built using Python and Tkinter.

## Features
- Connect to TV using IP address or auto-detect
- Volume control and mute
- App launcher
- Keyboard typing mode
- Power off control

## Download

Go to the Releases section and download the latest `.exe` file.

## How to Use

1. Run the `.exe`
2. Enter your TV IP or click "Auto Detect TV"
3. Click "Connect"
4. Accept the connection on   your TV
5. Start using the remote
